# Personal Landing Page


A **vibrant and responsive landing page** built purely with **HTML** and **CSS** to showcase personal information, skills, and domain interests. This project emphasizes clean design, smooth animations, and a user-friendly interface.

## Features
- **About Section:** Stylish profile image with a personal introduction.  
- **Skills & Tools:** Interactive boxes highlighting programming languages, frameworks, and tools.  
- **Domain Interests:** Showcases areas like Web Development, UI/UX, Machine Learning, and Cloud Computing.  
- **Contact Form:** Fun sticky-note style form for visitors to leave messages.  
- **Responsive Design:** Optimized for all screen sizes with smooth gradient backgrounds and hover effects.  
- **Modern Aesthetics:** Subtle animations, gradient backgrounds, and interactive elements enhance the visual appeal.
